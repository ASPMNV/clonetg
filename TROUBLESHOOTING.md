# Устранение проблем

## Проблемы с авторизацией Telegram

### Ошибка: "Invalid phone number"

**Причина:** Неправильный формат номера телефона

**Решение:**
- Используйте международный формат: `+79991234567`
- Включите код страны
- Не используйте пробелы и дефисы

### Ошибка: "Phone code invalid"

**Причина:** Неправильный код подтверждения

**Решение:**
- Проверьте код в Telegram
- Убедитесь, что код не истек (действителен 5 минут)
- Запросите новый код

### Ошибка: "Two-step verification enabled"

**Причина:** Включена двухфакторная аутентификация

**Решение:**
- Введите пароль облачного хранилища Telegram
- Если забыли пароль, сбросьте через Telegram

### Работа с файлом сессии

**Файл сессии:** `translator_bot.session` (или другое имя из `config.json`)

**Что это:**
- Файл содержит вашу авторизацию в Telegram
- Создается автоматически при первом запуске
- Позволяет не вводить код при каждом запуске

**Преимущества:**
- ✅ Не нужно вводить код при каждом запуске
- ✅ Можно перенести на другой сервер
- ✅ Работает без доступа к телефону

**Безопасность:**
- ⚠️ Храните файл в безопасности
- ⚠️ Не публикуйте в Git (уже в `.gitignore`)
- ⚠️ Не передавайте третьим лицам
- ⚠️ С этим файлом можно получить доступ к вашему Telegram

**Перенос на другой сервер:**
```bash
# Локально создайте сессию
python main.py
# Введите код, авторизуйтесь

# Скопируйте файл на сервер
scp translator_bot.session user@server:/path/to/bot/

# На сервере запустите без кода
python main.py
```

**Проблемы с сессией:**

1. **Сессия устарела**
   ```
   Ошибка: Session expired
   ```
   Решение: Удалите файл сессии и авторизуйтесь заново
   ```bash
   rm translator_bot.session
   python main.py
   ```

2. **Сессия повреждена**
   ```
   Ошибка: Database is malformed
   ```
   Решение: Удалите файл и создайте новую сессию
   ```bash
   rm translator_bot.session*
   python main.py
   ```

3. **Несколько устройств**
   - Можно использовать одну сессию на нескольких серверах
   - Но лучше создать отдельные сессии для каждого
   - Telegram может завершить старые сессии

4. **Смена номера телефона**
   - Удалите старый файл сессии
   - Обновите номер в `config.json`
   - Запустите и авторизуйтесь заново

## Проблемы с доступом к каналам

### Ошибка: "Channel not found"

**Причина:** Неправильный ID или username канала

**Решение:**
```bash
# Проверьте формат
# Правильно:
@channelname
-1001234567890

# Неправильно:
channelname
https://t.me/channelname
```

### Ошибка: "Access denied"

**Причина:** Нет доступа к каналу

**Решение для канала-источника:**
- Подпишитесь на канал
- Убедитесь, что канал публичный или вы в нем состоите

**Решение для целевого канала:**
- Убедитесь, что вы администратор
- Проверьте права на публикацию постов
- Добавьте бота в администраторы канала

### Как добавить бота в администраторы

1. Откройте целевой канал
2. Настройки → Администраторы → Добавить администратора
3. Найдите свой аккаунт (тот, что указан в `phone`)
4. Дайте права на публикацию сообщений

## Проблемы с Gemini API

### Ошибка: "Invalid API key"

**Причина:** Неправильный или недействительный ключ

**Решение:**
- Проверьте ключ на https://makersuite.google.com/app/apikey
- Создайте новый ключ
- Убедитесь, что скопировали ключ полностью

### Ошибка: "Quota exceeded"

**Причина:** Превышен лимит запросов

**Решение:**
- Добавьте больше API ключей в конфигурацию
- Увеличьте интервал проверки (`check_interval`)
- Уменьшите размер пакета (`batch_size`)
- Подождите до сброса квоты (обычно ежедневно)

### Ошибка: "Model not found"

**Причина:** Неправильное имя модели

**Решение:**
```json
"gemini": {
  "model": "gemini-3.5-flash"  // Проверьте актуальное имя
}
```

Актуальные модели:
- `gemini-3.5-flash` (рекомендуется, новая модель)
- `gemini-2.0-flash-exp` (экспериментальная)
- `gemini-1.5-flash`
- `gemini-1.5-pro`

## Проблемы с переводом

### Перевод не работает

**Диагностика:**
```bash
python utils/test_translation.py
```

**Возможные причины:**
1. Проблемы с API ключами
2. Нет интернет-соединения
3. Блокировка Google API в вашей стране

**Решение:**
- Проверьте API ключи
- Используйте VPN если Google заблокирован
- Проверьте логи: `tail -f logs/bot.log`

### Плохое качество перевода

**Решение:**
- Используйте более продвинутую модель (`gemini-1.5-pro`)
- Проверьте, что исходный текст не слишком короткий
- Убедитесь, что текст не содержит много специальных символов

## Проблемы с фильтрацией

### Слишком много постов фильтруется

**Причина:** Слишком строгие фильтры

**Решение:**
```json
"filters": {
  "spam_keywords": [],  // Уменьшите список
  "allowed_domains": ["*"],  // Разрешить все домены
  "remove_referral_params": false
}
```

### Спам проходит через фильтры

**Причина:** Недостаточно строгие фильтры

**Решение:**
```json
"filters": {
  "spam_keywords": [
    "реклама", "промокод", "скидка", "акция",
    "купон", "распродажа", "бесплатно", "выиграй"
  ]
}
```

## Проблемы с медиа

### Фото не отправляются

**Причина:** Проблемы с загрузкой медиа

**Решение:**
- Проверьте интернет-соединение
- Убедитесь, что есть права на скачивание из канала-источника
- Проверьте размер файла (Telegram лимит: 20MB для фото)

### Видео не отправляются

**Причина:** Превышен размер файла

**Решение:**
- Telegram лимит для ботов: 50MB
- Большие видео будут пропущены
- Рассмотрите возможность сжатия видео

## Проблемы с базой данных

### Ошибка: "Database is locked"

**Причина:** Несколько процессов пытаются использовать БД

**Решение:**
```bash
# Остановите все процессы бота
pkill -f main.py

# Проверьте, что нет других процессов
ps aux | grep main.py

# Запустите заново
python main.py
```

### Дубликаты постов

**Причина:** Проблемы с БД или сброс состояния

**Решение:**
```bash
# Проверьте БД
sqlite3 data/posts.db "SELECT COUNT(*) FROM processed_posts;"

# Если БД пуста, она будет пересоздана
# Чтобы избежать дубликатов, установите last_message_id вручную
```

## Проблемы с производительностью

### Бот работает медленно

**Причина:** Большой объем постов или медленный API

**Решение:**
```json
"processing": {
  "check_interval": 120,  // Увеличить интервал
  "batch_size": 5  // Уменьшить размер пакета
}
```

### Высокое использование памяти

**Причина:** Накопление данных в памяти

**Решение:**
- Перезапускайте бота раз в день
- Используйте Docker с ограничением памяти
- Очищайте старые логи

## Проблемы с Docker

### Контейнер не запускается

**Диагностика:**
```bash
docker-compose logs
```

**Решение:**
- Проверьте, что `config.json` существует
- Убедитесь, что все пути в `docker-compose.yml` правильные
- Проверьте права доступа к файлам

### Сессия Telegram не сохраняется

**Причина:** Файл сессии не примонтирован

**Решение:**
```yaml
volumes:
  - ./translator_bot.session:/app/translator_bot.session
```

## Частые вопросы

**Q: Можно ли использовать несколько каналов-источников?**
A: Нет, в текущей версии поддерживается только один канал. Запустите несколько экземпляров бота с разными конфигурациями.

**Q: Можно ли переводить на другие языки?**
A: Да, измените промпт в `src/translator.py`, заменив "тайский язык" на нужный.

**Q: Сколько API ключей нужно?**
A: Рекомендуется 3-5 ключей для стабильной работы в рамках free tier.

**Q: Бот пропускает старые посты?**
A: Да, при первом запуске бот начинает с текущего момента. Чтобы обработать старые посты, установите `min_id=0` в коде.

**Q: Можно ли запустить на бесплатном хостинге?**
A: Да, подойдут: Heroku, Railway, Render, Oracle Cloud (Always Free tier).

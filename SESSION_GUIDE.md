# Руководство по работе с сессиями Telegram

## Что такое файл сессии?

Файл сессии (например, `translator_bot.session`) - это файл базы данных SQLite, который содержит:
- Ключи авторизации в Telegram
- Информацию о вашем аккаунте
- Данные для автоматического подключения
- Параметры устройства (device_model, system_version и т.д.)

## Параметры клиента

Бот использует параметры клиента для идентификации в Telegram:

```json
{
  "device_model": "Desktop",
  "system_version": "Windows 10",
  "app_version": "4.8.1 x64",
  "lang_code": "en",
  "system_lang_code": "en-US"
}
```

**Зачем это нужно:**
- ✅ Telegram видит ваше устройство в списке активных сессий
- ✅ Помогает избежать блокировок
- ✅ Делает сессию более "легитимной"
- ✅ Соответствует официальным клиентам

**Где это видно:**
- Telegram → Настройки → Устройства
- Показывается как "Desktop, Windows 10"

## Как это работает

### Первый запуск

```bash
python main.py
```

**Что происходит:**
1. Telethon проверяет наличие файла `translator_bot.session`
2. Файла нет → запрашивает код из Telegram
3. Вы вводите код (и пароль 2FA если есть)
4. Telethon сохраняет авторизацию в файл
5. Создается `translator_bot.session`

**Вывод в консоли:**
```
Файл сессии не найден: translator_bot.session
Будет выполнена новая авторизация...
Please enter the code you received: 12345
✅ Авторизован как: Ваше Имя (@username)
✅ Сессия сохранена в файл: translator_bot.session
При следующем запуске авторизация не потребуется
```

### Последующие запуски

```bash
python main.py
```

**Что происходит:**
1. Telethon находит файл `translator_bot.session`
2. Читает ключи авторизации
3. Подключается к Telegram автоматически
4. Код не требуется!

**Вывод в консоли:**
```
Найден файл сессии: translator_bot.session
Попытка авторизации через сохраненную сессию...
✅ Авторизован как: Ваше Имя (@username)
✅ Использована существующая сессия
```

## Преимущества

✅ **Удобство**
- Не нужно вводить код при каждом запуске
- Автоматическое подключение

✅ **Портативность**
- Можно перенести на другой сервер
- Работает без доступа к телефону

✅ **Надежность**
- Сессия сохраняется между перезапусками
- Не зависит от наличия интернета на телефоне

## Безопасность

### ⚠️ Важно понимать

С файлом сессии можно:
- Читать ваши сообщения
- Отправлять сообщения от вашего имени
- Управлять вашими каналами
- Получить полный доступ к Telegram аккаунту

### 🔐 Как защитить

1. **Не публикуйте в Git**
   ```bash
   # Уже в .gitignore
   *.session
   *.session-journal
   ```

2. **Установите правильные права**
   ```bash
   chmod 600 translator_bot.session*
   ```

3. **Храните в безопасном месте**
   - Не на публичных серверах
   - Не в облачных хранилищах без шифрования
   - Не передавайте третьим лицам

4. **Шифруйте при хранении**
   ```bash
   # Зашифровать
   gpg -c translator_bot.session
   
   # Расшифровать
   gpg translator_bot.session.gpg
   ```

5. **Регулярно проверяйте активные сессии**
   - Telegram → Настройки → Конфиденциальность → Активные сессии
   - Завершите подозрительные сессии

## Перенос на другой сервер

### Способ 1: Прямое копирование

```bash
# На локальной машине
python main.py  # Создать сессию
# Авторизуйтесь

# Скопировать на сервер
scp translator_bot.session* user@server:/path/to/bot/

# На сервере
cd /path/to/bot
python main.py  # Запустится без кода!
```

### Способ 2: Через бэкап

```bash
# Локально
bash scripts/backup.sh

# Скопировать бэкап
scp backups/backup_*.tar.gz user@server:/path/to/bot/

# На сервере
tar -xzf backup_*.tar.gz
python main.py
```

### Способ 3: Docker

```bash
# Создать сессию локально
python main.py

# В docker-compose.yml уже настроено монтирование
docker-compose up -d
```

## Проблемы и решения

### Сессия устарела

**Симптомы:**
```
Error: Session expired
Error: Unauthorized
```

**Причины:**
- Сессия была завершена в Telegram
- Изменился пароль аккаунта
- Telegram завершил старые сессии

**Решение:**
```bash
rm translator_bot.session*
python main.py
# Авторизуйтесь заново
```

### Сессия повреждена

**Симптомы:**
```
Error: Database is malformed
Error: file is not a database
```

**Причины:**
- Файл поврежден
- Неполное копирование
- Сбой диска

**Решение:**
```bash
rm translator_bot.session*
python main.py
# Создайте новую сессию
```

### Несколько устройств

**Вопрос:** Можно ли использовать одну сессию на нескольких серверах?

**Ответ:** Технически да, но:
- ⚠️ Могут быть конфликты
- ⚠️ Telegram может завершить старые сессии
- ✅ Лучше создать отдельные сессии для каждого сервера

**Как создать несколько сессий:**
```bash
# Сервер 1
session_name: "bot_server1"

# Сервер 2
session_name: "bot_server2"
```

### Смена номера телефона

**Если вы сменили номер в Telegram:**

```bash
# 1. Удалить старую сессию
rm translator_bot.session*

# 2. Обновить config.json
# "phone": "+79991234567"  # Новый номер

# 3. Запустить
python main.py
# Введите код на новый номер
```

## Управление сессиями

### Просмотр активных сессий

**В Telegram:**
1. Настройки → Конфиденциальность и безопасность
2. Активные сессии
3. Найдите "Telegram Bot" или название вашего приложения

**Информация:**
- Дата создания
- IP адрес
- Местоположение
- Последняя активность

### Завершение сессии

**В Telegram:**
- Нажмите на сессию → Завершить сессию

**Результат:**
- Бот потеряет доступ
- При следующем запуске потребуется код

**На сервере:**
```bash
# Удалить файл сессии
rm translator_bot.session*

# Или переименовать
mv translator_bot.session translator_bot.session.old
```

### Ротация сессий

```bash
#!/bin/bash
# rotate_session.sh

# Проверить возраст сессии
AGE=$(find translator_bot.session -mtime +30 2>/dev/null)

if [ -n "$AGE" ]; then
    echo "Сессия старше 30 дней, пересоздание..."
    rm translator_bot.session*
    python main.py
fi
```

## FAQ

**Q: Как долго действует сессия?**
A: Бессрочно, пока вы не завершите её в Telegram или не измените пароль.

**Q: Можно ли восстановить удаленную сессию?**
A: Нет, нужно создать новую (ввести код заново).

**Q: Безопасно ли хранить сессию на сервере?**
A: Да, если сервер защищен и файл имеет правильные права доступа (600).

**Q: Что делать если файл сессии украли?**
A: Немедленно завершите все сессии в Telegram → Настройки → Активные сессии.

**Q: Можно ли использовать бота без файла сессии?**
A: Нет, Telethon требует сессию для работы. Но она создается автоматически.

**Q: Где хранится файл сессии?**
A: В корневой директории проекта, имя из `config.json` → `telegram.session_name`.


Обычно 20-100 KB. Если файл намного больше - возможно повреждение.

- ✅ Разными версиями Telethon
